# 字符串

## hash

### 想法

这里记录的是最常见的一种哈希：**进制哈希**。

~~字符串hash是一种hash~~ 为了做到字符串的快速相等比较，而不是一个个比对，有一种从字符串到整数的映射，这是字符串哈希（我自己总结的，官方定义看[oiwiki](https://oi-wiki.org/string/hash/)吧）
那它具体是啥呢 进制哈希的核心便是**给出一个固定进制 $base$ ，将一个串的每一个元素看做一个进制位上的数字，所以这个串就可以看做一个 $base$ 进制的数，那么这个数就是这个串的哈希值；则我们通过比对每个串的的哈希值，即可判断两个串是否相同**。--[皎月半洒花](https://www.luogu.com.cn/user/28313)大佬

非常好理解。

	ans = (ans * base + (ull)s[i]) % mod + prime;

## trie

### 想法

这你会了吧

### 代码

我都帮你封装好了。![嘟·嘟嘟嘟](/img/image.png)

```cpp
struct Trie
{
	int tot;
	int ch[M][26];
	bool ed[M];

	int g[26][26];
	int vis[26];

	void insert(string x)
	{
		int now = 1;
		for (int i = 0; i < (int)x.size(); i++)
		{
			int c = x[i] - 'a';
			if (!ch[now][c])
				ch[now][c] = ++tot;
			now = ch[now][c];
		}
		ed[now] = true;
	}

	bool dfs(int x)
	{
		vis[x] = 1;
		for (int i = 0; i < 26; i++)
		{
			if (g[x][i])
			{
				if (vis[i] == 1)
					return false;
				if (vis[i] == 0 && !dfs(i))
					return false;
			}
		}
		vis[x] = 2;
		return true;
	}

	bool check(string x)
	{
		memset(g, 0, sizeof(g));
		memset(vis, 0, sizeof(vis));

		int now = 1;
		for (int i = 0; i < (int)x.size(); i++)
		{
			if (ed[now])
				return false;

			int c = x[i] - 'a';
			for (int j = 0; j < 26; j++)
			{
				if (j != c && ch[now][j] && !g[c][j])
					g[c][j] = 1;
			}
			now = ch[now][c];
		}

		for (int i = 0; i < 26; i++)
		{
			if (!vis[i] && !dfs(i))
				return false;
		}
		return true;
	}
} tr;
```
